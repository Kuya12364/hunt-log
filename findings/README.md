# Findings

One file per reported finding. Each one is a summary card: target, date,
severity, status, and a one-line description of the bug class.

No endpoints, no payloads, no request or response bodies, no reproduction
steps. That material goes to the vendor privately. Once a finding is public
and fixed, the write-up gets linked here.
